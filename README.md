# Edge AI Lab: code from the videos

Every experiment, benchmark and build from the **Edge AI Lab** YouTube channel, one folder per video:
AI on tiny, cheap hardware instead of the cloud (ESP32 microcontrollers, a Raspberry Pi Zero, laptop
NPUs), with the numbers measured on my own boards.

Each folder has its own README: what the video was about, how to run the code, my results, and the
caveats. If you run something, post your numbers under the video. That's the fun part.

## Videos

| # | Video | Folder | What's inside |
|---|---|---|---|
| 16 | Why Every Chip Suddenly Has an NPU | [`16-npu`](16-npu) | CPU vs GPU vs Neural Engine benchmark for Apple Silicon (Core ML) |
| 17 | NVIDIA Squeezed a 74B AI Into 2 Bits. So I Tested It. | [`17-two-bit`](17-two-bit) | 2-bit vs 4-bit vs 8-bit at the same memory: Qwen3 + llama.cpp benchmark |

## Layout

```
NN-slug/            one folder per video, numbered like the episodes
  README.md         the video, how to run it, my results, caveats
  ...               the code, plus requirements.txt / platformio.ini / whatever it needs
_template/          copy this to start a new folder
```

Big files stay out of the repo: models, datasets and build outputs are downloaded or generated by the
code (see each README), never committed.
